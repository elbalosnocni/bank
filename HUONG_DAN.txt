HE THONG THI TRUC TUYEN / KHAO SAT V10

1. CAC FILE
- Code.gs: backend Google Apps Script.
- index.html: giao dien nhan vien/nguoi lam bai.
- admin.html: giao dien quan tri.
- index-tinhxaphuong.html: file tham khao ban dau do nguoi dung cung cap; khong can upload rieng vao GitHub Pages.

2. CAP NHAT TU V9 LEN V10
- Sao luu Google Sheet va cac file GitHub hien tai.
- Thay Code.gs bang ban V10; giu nguyen SPREADSHEET_ID va cac Script Properties dang dung.
- Trong Apps Script, chay setupSheets() mot lan de bo sung cot FormDescription (cot I) trong CaiDatDeThi. Ham setupSheets khong xoa dong du lieu.
- Cap nhat index.html va admin.html V10 len GitHub Pages.
- Deploy > Manage deployments > Edit > New version > Deploy.
- Kiem tra GAS_URL trong ca hai file HTML va thay bang URL /exec dang dung.

3. MO TA FORM VA CAU HOI
- Admin > Mon & cai dat: truong Form description luu vao cot I FormDescription cua CaiDatDeThi.
- Admin > Ngan hang cau hoi: Question description duoc luu trong JSON cau hinh o cot TruongTraLoi (cot P), khong them cot moi.
- Voi loai SECTION, Question description duoc hien thi nhu Section Description (optional).
- Cau hoi moi mac dinh duoc danh dau bat buoc. Bo chon “Bat buoc tra loi (*)” neu muon cau hoi tuy chon.
- Truong con MULTI_FIELD van co the danh dau bat buoc bang dau * o dau dong. “Toi khong co y kien” bo qua cac truong con.
- Cac cau hoi V9 cu khong co metadata required se mac dinh khong bat buoc, de tranh bat buoc nham cac cau cu.

4. KIEM TRA LOI VA GUI BAI
- Trang nguoi lam bai giu lai toan bo cau tra loi khi co loi.
- Khi bam Gui bai, giao dien kiem tra cau bat buoc va dinh dang SHORT_TEXT (chi so, do dai, min/max), danh dau cac cau loi va cuon den cau loi dau tien.
- Backend kiem tra lai va tra ve danh sach loi theo ID cau hoi; giao dien khong xoa noi dung bai lam khi server tu choi.
- Khi khong con loi, nguoi lam bai xac nhan ket thuc. Sau khi gui thanh cong, trang hien thi ket qua/diem va thong ke tung cau tra loi.
- Thanh tien do co dinh ben duoi tieu de mon thi/khao sat; SECTION khong tinh vao tong so cau.

5. DROPDOWN TINH / XA-PHUONG
- Trong Admin, chon loai DROPDOWN va “Tinh / Thanh pho -> Xa / Phuong (du lieu VietnamProvinces)”.
- Giao dien se tai JSON nested-divisions, hien danh sach tinh/thanh pho; khi chon tinh se nap cac xa/phuong tu thuoc tinh wards.
- Luu ten va ma tinh, ten va ma xa/phuong trong PhanHoi.
- Nguon CDN duoc dat trong index.html tai bien GEO_DATA_URL. Neu nha cung cap doi duong dan/branch, can cap nhat bien nay.
- File index-tinhxaphuong.html goc co DATA_URL='https://jsdelivr.net', day khong phai URL JSON nen khong dung truc tiep duoc. Cau truc ma file goc mong doi (province.name/code/wards) phu hop voi dang nested data cua VietnamProvinces, nhung URL can phai tro den file JSON cu the.
- Du lieu cua sunshine-tech/VietnamProvinces mo ta don vi hanh chinh cap tinh va xa/phuong sau sap xep thang 7/2025. README repo hien ghi data version 2026-02-21; can doi chieu lai neu co thay doi hanh chinh moi hon.

6. DASHBOARD BAO CAO ADMIN
- Tab Bao cao hien thi so luot nop, tong phan hoi, diem trung binh, luot nop theo mon/bo phan va 20 luot nop gan nhat.
- Tab Bang diem van xem chi tiet ket qua thi.
- Tab Tong hop y kien tiep tuc nhom cau tra loi tuong tu dua tren token/Jaccard; day la nhom tu khoa tham khao, khong phai AI doc hieu ngu nghia. Nen doc lai noi dung goc truoc khi ket luan.

7. CAC LUU Y KY THUAT
- V10 khong doi cau truc 16 cot cua NganHangDe; description, required va geoType duoc luu trong JSON o cot TruongTraLoi.
- V10 them cot I FormDescription trong CaiDatDeThi. Chay setupSheets() mot lan sau khi cap nhat Code.gs.
- Khong thay SPREADSHEET_ID bang gia tri mau. Khong thay mat khau Admin hoac CCCD_HMAC_SECRET trong Script Properties.
- Kiem thu it nhat: 1 mon OPINION, 1 mon GRADED, cau SHORT_TEXT so, cau bat buoc bo trong, cau khong bat buoc, MULTI_FIELD co dau *, SECTION, dropdown tinh/xa-phuong va dashboard.
